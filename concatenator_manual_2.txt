5.10 Data Combiner Module
See also:
Data Merging Modules Comparison
Data Combiner combines the fields of two inputs into the same array without matching the records, i.e. the first
record from input A (top connector) will be combined with the first record from input B (bottom connector) and
the second with second, etc.
The intention is to combine sets of data with the same number of records when it is known that both sets are in
the desired order. If the number of records differs, the resulting number of records is that of the input with the
highest number of records, i.e. no records are lost. The fields from the input with less records are left empty for
the remaining combined records.
If there are fields with the same name in both inputs, they will be merged into a single field with that same name.
In that field, the values in the fields from input B will overwrite the values coming from input A, unless there are
less records in input B than input A, in which case all the values from input B will be used first, succeeded by records
with values from input A.
If you know that it is OK to overwrite a field from A because the values are the same in both inputs, you should
also make sure that the records are in the same order, e.g. by sorting the fields using theData Sorter module. If
you do not want those fields of the same name to be merged and overwritten, use theData Field Renamer
module first to rename one of the fields.
